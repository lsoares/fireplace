# Fireplace

Cozy live streams for Stremio, 24/7: a fireplace, lofi, rain and synthwave, as the first row, then the best of the groups, and groups of music, nature, animals, space, ASMR and trains. Each group is a row of its own on the Board. Only the best is on by default; the others are chosen on the page.

**Install:** open **https://lsoares.github.io/fireplace/**, choose the groups, then **Install**, or paste `https://lsoares.github.io/fireplace/manifest.json` in Stremio's addon search.

It is a static site: no server, nothing kept. The files Stremio asks for (`manifest.json`, `catalog/…`, `meta/…`, `stream/…`) are generated by `npm run build`, one folder for each choice of groups (`groups=best,space/`; the plain `manifest.json` is only the best, the default), and published with GitHub Pages at each push to `main`. The videos play with YouTube's own player.

```bash
npm install
npm run check     # Biome, Knip, type check and tests (also run before every push)
npm run embeds    # tests which videos let embed (needs a browser: `npx playwright install chromium`)
npm run preview   # builds the site and serves it at http://127.0.0.1:7003
```

Only videos that allow embedding are listed, as the others do not play in Stremio. Each group is a pool with more videos than a row has room for (ten); every day, and at each push, `npm run embeds` plays them all in a browser with YouTube's player (error 150 means it is not allowed) and writes the ones that fail to `blocked.json`, which `npm run build` leaves out, so the next of the pool takes their place. The fireplace is always the first video. The list of videos is `src/live.ts`; the best is picked there by hand, from the videos of the groups.
